# 🤖 AI Fluency Training — Day 1 Lab

## From LLMs to Agents: Chatbot, Workflow and AI Agent

This repository contains my Day 1 AI Fluency Training lab implementation.

The lab demonstrates three different approaches to solving college course-related tasks:

1. **Plain LLM Chatbot**
2. **Rule-Based Workflow**
3. **Tool-Using AI Agent**

The purpose of this lab is to understand how an LLM-based chatbot differs from a fixed workflow and how an AI agent can use tools to access application-specific information and perform calculations.

# 🎯 1. Objective

The objectives of this lab are:

- Set up Python development in VS Code.
- Create a Python virtual environment.
- Connect a Python application to an open LLM.
- Build a plain LLM chatbot.
- Build a rule-based workflow.
- Build tools for course-fee lookup and calculations.
- Build a tool-using AI agent.
- Compare chatbot, workflow, and agent approaches.
- Understand how tools provide application-specific information.
- Test the systems using common questions.
- Solve a new course-budget challenge.
- Practice Git and GitHub for project submission.
